# Project Lihini - Weather Monitoring System 🌦️

Welcome to the Project Lihini repository! This project offers a real-time, responsive, and insightful solution for weather data tracking, built with modern technologies for robust and efficient performance. 

## 🌐 Overview

This system is designed to provide users with real-time weather data, including temperature, humidity, light intensity, and more. Data collected from IoT devices is processed and presented through an intuitive web interface, allowing users to visualize weather trends and make informed decisions.

## 🛠️ Technology Stack

- **Frontend**: for creating a dynamic and responsive user interface.
- **Backend**: for handling server-side operations and API requests.
- **Database**: Efficient storage solution for managing real-time weather data.
- **IoT Devices**: ESP32 sensors for accurate, real-time data collection from the environment.

## 🚀 Features

- **Real-time Data Collection**: Continuously fetch and display up-to-date weather conditions.
- **User-Friendly Interface**: Intuitive design with clear, visualized weather insights.
- **Interactive Dashboard**: Explore historical data trends and monitor weather metrics.
- **Customizable Notifications**: Get alerts based on specific weather conditions.
- **Responsive Design**: Works seamlessly on desktops, tablets, and mobile devices.

## 📂 Project Structure

- **/client**: Contains the React frontend code.
- **/server**: Contains the Node.js backend code and API logic.
- **/database**: Manages data storage for historical weather records.
