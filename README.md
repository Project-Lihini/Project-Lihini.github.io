# Project Lihini Website

![Poster](./assets/Cover.png)

> The open-source, crowd-funded weather data platform.

The purpose of this project is to build a project that is fully open source, including all the hardware designs as well as the software development. This is what Project Lihini aims to build: an open source, crowd-sourced weather monitoring platform. Project Lihini will include hardware, software, and all monitoring data open to the public.

Everything related to the project including the design files and software will be available on a central location. The community will be able to discuss and involve in the decision making, while also being able to involve in the development. Everything will be released under an open-source license.

It is important as discussed before, to create a welcoming environment for educational purposes. Thus, where will be a strict code of conduct to ensure that no one is left behind and everyone is allowed to contribute. There will be a platform to discuss and involve with the decision making. Anyone will be allowed to contribute with the development through Git.

Project Lihini addresses the need for a flexible and publicly shareable system for collecting and disseminating environmental data, fostering community engagement and learning within the open-source domain.
